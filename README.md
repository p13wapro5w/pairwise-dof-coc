# pairwise-dof-coc

景深在焦距从远景拉到近景时前景边缘出现一圈硬边，CoC 按像素半径算却没随分辨率缩放，半分辨率颜色缓冲上采样后高光被拉成方块；透明粒子的 CoC 用了不透明深度，前后景遮挡关系翻转；时域抖动样本在焦距变化时没重置，画面拖出同心圆鬼影；切镜后历史 CoC 未清空，上一镜的焦外圆盘叠到新镜；bokeh 采样盘固定 16 tap，亮部出现多边形；近平面裁剪导致 CoC 饱和，贴脸物体整块糊；景深后处理在 HDR 前做，色调映射把焦外高光压扁；多相机分屏共用一个 CoC 纹理，左右眼焦距互相污染；性能档位切换时 kernel 半径变了但权重没归一，亮度跳变。render/depth_of_field.py 是核心，tests/test_depth_of_field.py 15个红。要修的是：CoC 按分辨率与焦距重算；半分辨率按深度边界联合上采样；透明用预乘深度；焦距变化重置历史；切镜清 CoC 历史；bokeh 采样按能量归一；近平面 CoC 软饱和；景深放到 HDR 线性空间；多相机独立 CoC；切档重算权重。

## 运行

```bash
python -m pytest tests -q
```

初始状态：15 个用例失败。修复实现使全部用例通过，不要修改 `tests/` 下的测试。
